# County Cars Privacy Policy

Static, dependency-free GitHub Pages site for the County Cars privacy policy.

## Publish with GitHub Pages

In the repository on GitHub, open **Settings → Pages**, set the build and deployment source to **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.

The site will be available at:

<https://baselamin1.github.io/County-Cars-Privacy-Policy/>
